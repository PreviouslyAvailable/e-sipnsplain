# Shadow of the Colossus — PS2 UI/HUD/Menu Aesthetics

## Title Screen

- **Look:** Dark, desaturated. The original PS2 title screen uses a subdued palette — deep browns, ochres, and near-black shadows suggesting antiquity and scale. No animation flourishes; a static or very slow-moving atmospheric scene.
- **Type treatment:** The logotype uses **Caslon Antique** (a decorative display face designed by Berne Nadall, 1894) — a serif with antiqued, slightly eroded strokes that reads as ancient/worn stone inscription. The lettering is large, centered, and spaced with commanding negative space.
- **Color tone:** Muted earth palette — charcoal (`~#1a1410`), aged parchment (`~#c8a96e`), and bone white (`~#e8dfc8`) for the title type. No vivid saturation; the overall impression is desaturated sepia-bronze.

## Menu / Pause Menu Pattern

- **Philosophy:** Design by subtraction (the Ueda / Team Ico ethos, shared with Ico). Non-essential UI elements are either removed or made as unobtrusive as possible.
- **Pause menu:** Minimal — typically just a bare list in the same Caslon-influenced aesthetic; very little chrome. No gradient panels, no translucent overlays. Black or near-black background.
- **Font:** In menus, a complementary antiqued serif consistent with the title logotype is used. Thin strokes, moderate tracking. Not a system font — custom-styled to the game's ancient-ruin atmosphere.

## HUD Elements (PS2 Original)

- **Vitality (health) bar:** Small, situated at the bottom or corner of screen. In the PS2 original, the health bar used **bland neutral coloring** — deliberately muted so it would not break immersion. Community consensus: the original's HUD was notably less obtrusive than the 2018 PS4 remake (which added brighter colors that players criticized as "too gaudy").
- **Grip gauge (stamina):** The stamina/grip bar in the PS2 original was **pink** in color. In the PS4 remake this changed to yellow. The grip gauge appears radially (grows as a ring) in the PS2 version around the action prompt area; it indicates how long Wander can cling to a Colossus.
- **Weapon/bow indicator:** Small icon, appears contextually only when relevant.
- **No map, no compass, no minimap.** The sword mechanic (hold up sword to refract light toward the next Colossus) replaces waypoint markers entirely.
- **Arrow/reticle marker:** Early builds had a distinctive arrow reticle; the shipped version was further pared down.
- **HUD visibility:** Elements appear only when gameplay requires — during colossus climbing or low health; invisible during open-world traversal. This "diegetic suppression" was intentional.

## Font Character

| Property | Value |
|---|---|
| Title font | Caslon Antique (serif, antiqued/eroded strokes) |
| Weight | Regular to Medium — not bold |
| Tracking | Wide — commanding negative space |
| Style | Decorative display serif; aged/stone-inscription feel |
| In-game text | Thin serif or antiqued letterforms matching logotype |

## Color Palette / Grading

| Name | Approx Hex | Usage |
|---|---|---|
| Deep Charcoal | `#1a1410` | Background, title screen base |
| Aged Parchment | `#c8a96e` | Title logotype warm tone |
| Bone White | `#e8dfc8` | Secondary text, highlights |
| Muted Ochre | `#8b6f3a` | Atmospheric mid-tones |
| Vitality Bar (neutral) | `~#a8a890` | PS2 HUD health — muted, near-grey |
| Grip Bar (pink) | `~#d4607a` | PS2 HUD grip gauge |

**Overall grading philosophy:** Fumito Ueda and Team Ico deliberately used overexposed, desaturated light in the in-game world itself. The visual style mimics aged photography — warm highlights that bleed into surrounding areas (bloom), muted shadows with no pure black, and an almost hand-painted atmospheric quality. The UI inherits this palette: nothing vivid, nothing that pops against the world.

## Cross-Reference Notes

- Shares the "design by subtraction" philosophy with **Ico** (same director, same studio).
- The Caslon Antique title font establishes the "ancient civilization" category of PS2-era game UI — compare to other games using distressed serif type for mythological settings.
- The PS2 HUD's muted neutral coloring was a deliberate choice to preserve immersion; the remake's brighter HUD was criticized for breaking this.
