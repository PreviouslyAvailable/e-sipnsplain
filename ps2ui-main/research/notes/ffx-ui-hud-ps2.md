# Final Fantasy X — PS2 UI / HUD / Menu Aesthetics

## Title Screen

- **Color**: Deep ocean blue-black background with soft glowing light shafts. Water caustics / light-through-water shimmer animation. The title logo ("FINAL FANTASY X") appears in a luminous off-white/cream serif, backed by a subtle gold inner glow.
- **Type treatment**: Logo uses a tall, elegant serif with moderate tracking — community font IDs on dafont.com point to **Optima** (Hermann Zapf, 1958) or a close custom derivative for the in-game subtitle/menu text. The FFX wordmark itself is custom-lettered. Optima is a humanist sans-serif with flared stroke endings — it reads as "serif-adjacent" without being a true serif.
- **Motion**: Slow dissolve from black; water ripple effects; Tidus silhouette; orchestral swell. No hard cuts — all soft fades and light blooms.

## Main Menu / Pause Menu

- **Layout**: Vertical list on the left side of the screen; party member portraits run along the right. Menu entries are left-aligned in a translucent dark-blue panel with a faint gradient fade (darker at top, slightly lighter at bottom).
- **Panel style**: Semi-transparent dark navy blue overlay (`approx #001A3A` at ~75% opacity), with a thin lighter-blue border line (approx `#3399CC`). No hard opaque boxes — all panels have visible translucency against the game world behind them.
- **Font**: Optima or Optima-like humanist sans — medium weight, moderate tracking (~0.05em). All-caps for category headers; mixed case for item names. Clean, legible at PS2 resolution.
- **Sub-menus**: Items, Equipment, Magic, Summoning, Sphere Grid, Save — each opens a full-panel overlay maintaining the same translucent blue system. Equipment menu shows character model on right, stat numbers in pale yellow/cream against the blue.
- **Cursor**: A small glowing pale-blue chevron or arrow indicator. Selected item brightens to full white.

## HUD (In-Battle)

- **Party HP/MP bars**: Displayed bottom-left or bottom-right depending on version. Bars are segmented, rendered in a warm yellow-orange for HP and a cool blue-teal for MP against a dark translucent backing.
- **ATB/CTB order display**: FFX uses a Conditional Turn-Based system. The turn order panel (right side) shows character and enemy portraits in a vertical queue — a novel UI element. Icons are small, bordered in metallic silver-blue.
- **Action command menu**: Bottom-left, same translucent blue panel language as the main menu. Options: Attack, Magic, Skills, Items, Summon, Use, Escape. Font matches the main menu Optima-like weight.
- **Damage numbers**: Large, bold, white numerals with a thin dark outline — appear floating above targets and fade quickly upward.
- **Overdrive gauge**: A yellow-orange horizontal progress bar labeled "OVERDRIVE" in small all-caps. When full, pulses with a warm amber glow.

## Font Character

- **Primary**: Optima (or near clone) — humanist sans with slightly flared stroke endings; medium weight; moderate tracking. Not a true serif but reads "warm" and slightly classical. Gives the interface elegance without austerity.
- **Numbers**: Same font family, regular weight.
- **English logo**: Custom lettering. Similar proportions to Trajan/Optima hybrids common in Square games of the era.
- The original PS2 version used a noticeably more "colorful" and warmer blue than the HD Remaster's colder, more modern redesign (documented in GameFAQs player discussions).

## Design Signature

FFX's menus establish the "translucent blue crystal" language: every panel is a dark navy glass overlay, never fully opaque. The aesthetic echoes Spira's water-world — the HUD itself feels submerged. The combination of warm Optima-like type against cool translucent panels creates an approachable elegance that is distinctly JRPG-late-PS2-era.
