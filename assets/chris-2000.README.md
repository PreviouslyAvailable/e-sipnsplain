# Chris, 2000 — era photo

**Swap this file:** drop your photo as [`chris-2000.png`](./chris-2000.png) in this folder.

- Used by Desktop Themes → **Chris, 2000** (Section 2 exit reveal).
- Wired in `js/moments/w98-themes.js` as `CHRIS_2000_PHOTO` (`/assets/chris-2000.png`).
- Optional alternate: `assets/years/` — if you prefer a years folder, update `CHRIS_2000_PHOTO` to match.

The current PNG is a teal placeholder so the path loads offline.
