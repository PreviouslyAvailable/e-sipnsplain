# PS2 assets

## Logo (load / start screen)

`ps2-logo.png` — PS2 mark on the XP shut-down → living-room handoff
(black → TV static fade → logo → Press to start) and again on the `#consoles`
PS2 splash (black bg, logo upper-center, Press to start below).

## Boot audio

The PS2 boot sequence loads `ps2-boot-audio.mp3` from this directory.

```text
assets/ps2/ps2-boot-audio.mp3
```

It starts when the boot towers appear and stops if the presenter advances,
leaves the PS2 chapter, or presses `M` to mute.
